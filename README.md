## Re-map your Local Remotes
- Rename the original source: `git remote rename origin upstream`
- Add your new repo as "origin": `git remote add origin https://github.com/godey4me/my-new-repo.git`
- Verify the final setup run `git remote -v`
- Push your code to your new repo: `git push -u origin rishov`
- To get their new code: `git pull upstream rishov`
- To save your progress: `git add.`,  then `git commit -m "notes"`,  then `git push origin risov`
- To get updates from the original source:  
     `git checkout rishov`
     `git pull upstream rishov`
- To push your changes to your own repo:  
     `git add .`  
     `git commit -m "Your descriptive message"`  
     `git push origin main`
