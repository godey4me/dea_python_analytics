## Group Exercises

### ETL - API to MongoDB to PostgreSQL

1. Access an API endpoint from [RapidAPI](https://rapidapi.com/).

2. Pass your API response as an object in a MongoDB collection.

3. Retrieve your objects in the collection and normalize into a DataFrame.

4. Load the normalized DataFrame into a PostgreSQL table.
