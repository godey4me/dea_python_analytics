## Streamlit Introduction

### Description

- `Streamlit` is a web application framework in Python that allows developers to create applications only using Python.

### Installation and Setup

1. Install `streamlit` via `pip`.

```bash
pip install streamlit
```

### Basic Usage

1. Start a web application.

- Create a `app.py` file.

```python
import streamlit as st

# Add any widget from streamlit
st.title("Basic Web App")
```

2. Run the web application using the Streamlit CLI.

```bash
streamlit run app.py
```
